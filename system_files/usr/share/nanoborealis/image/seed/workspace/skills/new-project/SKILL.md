# New project

## Steps

1. **Pin down the goal in one sentence.** If the request is ambiguous in a way that changes what you'd build, ask one question first.
2. **Create it in `~/projects/<short-name>/`**, the folder shared with me, and run `git init` there.
3. **Pick the simplest stack that does the job,** preferring what's already installed. Pin dependency versions.
4. **Get a runnable version fast:** the smallest thing that works end to end. Run it and show me the output before adding features.
5. **Grow it in small verified steps,** running it again after each one.
6. **Write a short README.md:** what it is, how to install its dependencies, how to run it, and how to test it.
7. **Commit at each working milestone,** following the git-workflow skill.

## Output

- Where it lives, how to run it, and what you verified.
- Anything unfinished or uncertain, stated plainly.

## Do not

- Do not scaffold a large framework for a small task.
- Do not leave it in a state that doesn't run without telling me.
